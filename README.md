# Название репозитория

## Описание

Обработка и получение cbow эмбеддингов аварских текстов.(Итоговые эмбеддинги в файле final_avaric_dict.npy)

### Содержимое репозитория

- **raw_corpus**
  Директория с необработанными текстам

- **processed_corpus**
  Директория с обработанными текстами

- **processing**
  Директория с тестами в процессе обработ

- **extracting.py**
  Извлечение.

- **Gamzatov_10tom.pdf**  
  Исходный PDF-файл, содержащий текст для дальнейшей обработки.

- **input.txt**  
  Файл, в который записаны предложения из газет.

- **pdf_links.txt**  
  Файл со ссылками на источники, откуда были взяты газеты.

- **make_avaric_sentences.py**  
  Скрипт на Python, предназначенный для извлечения и обработки текста из PDF. Он удаляет все знаки препинания и оставляет только предложения, содержащие более двух слов.

- **tolow.py**  
  Скрипт для преобразования текста в нижний регистр. Он:
  - Читает входной файл,
  - Обрабатывает каждую строку, переводя её в нижний регистр,
  - Записывает результат в выходной файл.  
  *(Примечание: в аварском языке некоторые буквы записываются как сочетание маленькой буквы из кириллицы и латинской большой буквы I, для простоты они будут заменены на маленькую букву i.)*

- **lemmatizator.py**  
  Скрипт для лемматизации аварских слов. Он выполняет следующие действия:
  - **Запрос леммы:**  
    Для каждого аварского слова функция `getlemma` отправляет HTTP-запрос к API (на `https://avar.me/api/`), чтобы получить лемму слова. Если лемма не найдена или происходит ошибка, слово помечается префиксом `!!`.
  - **Подсчёт строк:**  
    Функция `get_file_line_count` определяет количество строк в заданном файле, что позволяет скрипту продолжать обработку с того места, где она была остановлена.
  - **Обработка файлов:**  
    Функция `process_file` считывает предложения из входного файла, обрабатывает каждую строку, разбивая её на отдельные слова, и для каждого слова пытается получить его лемму. Результат записывается в выходной файл. При этом ведётся подсчёт общего количества слов и успешных лемматизаций, а также выводится прогресс обработки.

- **familia.py**  
  Скрипт для обработки фамилий в тексте. Он осуществляет следующие шаги:
  - **Определение суффиксов:**  
    В начале скрипта заданы списки окончаний (суффиксов) для фамилий и патронимов, характерных для различных групп (новые окончания, лезгинские и аварские окончания). Все окончания объединяются и сортируются по убыванию длины, чтобы корректно обрабатывать случаи, когда одно окончание может быть вложено в другое.
  - **Проверка фамилии:**  
    Функция `is_surname(word)` проверяет, заканчивается ли слово (без учета регистра) на один из известных суффиксов, определяя, является ли слово фамилией.
  - **Замена фамилий:**  
    Функция `replace_surname(match)` используется в регулярном выражении для замены найденного слова. Если слово определяется как фамилия, оно заменяется на токен `"fam"`, иначе остаётся без изменений.
  - **Обработка файла:**  
    Функция `process_file` считывает содержимое входного файла, заменяет слова, определённые как фамилии, на токен `"fam"`, и записывает результат в новый файл.

- **avaric_token.py**  
  Скрипт для токенизации аварского текста. Он предназначен для замены аварских числительных и местоимений на соответствующие токены:
  - **Списки токенизации:**  
    Заданы множества аварских числительных и местоимений с вариантами написания.
  - **Обработка строки:**  
    Функция `process_line` разбивает строку на слова и заменяет:
    - каждое слово, которое содержится в наборе числительных, на токен `"di"`,
    - каждое слово, которое содержится в наборе местоимений, на токен `"pron"`.
  - **Обработка файла:**  
    Функция `process_file` считывает входной файл (где каждая строка представляет собой предложение), обрабатывает каждую строку с помощью `process_line` и записывает результат в выходной файл.

- **tokendigits.py**  
  Скрипт для замены слов, содержащих цифры, на токен для числительных:
  - **Обработка строки:**  
    Функция `process_line` разбивает строку на отдельные слова, проверяет каждое слово с помощью регулярного выражения на наличие цифр. Если слово содержит хотя бы одну цифру, оно заменяется на токен `"di"`, иначе остаётся без изменений.
  - **Обработка файла:**  
    Функция `process_file` считывает все строки из входного файла, обрабатывает каждую строку функцией `process_line` и записывает обработанные строки в новый выходной файл.

- **remover.py**  
  Скрипт для удаления из текста строк, содержащих менее трёх слов, а также для очистки неудачных лемматизаций:
  - **Фильтрация строк:**  
    Скрипт читает входной файл построчно. Если строка содержит менее трех слов, она пропускается.
  - **Очистка слов:**  
    Для каждого слова в строке, если слово начинается с префикса `"!!"` (что указывает на неудачную лемматизацию), этот префикс удаляется.
  - **Запись результата:**  
    Обработанная строка записывается в выходной файл.
- **levenshtein.py**  
  Скрипт для исправления некорректных лемм с помощью алгоритма расстояния Левенштейна. Он выполняет следующие задачи:
  - **Вычисление расстояния Левенштейна:**  
    Функция `levenshtein_distance(s1, s2)` вычисляет расстояние Левенштейна между двумя строками, позволяя оценить схожесть слов.
  - **Построение словаря лемм:**  
    Функция `build_dictionary(sent_path, lemma_path)` считывает пары предложений и лемм из файлов и создает словарь вида `{слово: лемма}`, игнорируя некорректные леммы, начинающиеся с префикса `!!`.
  - **Генерация соседних слов:**  
    Функция `generate_neighbors(word, alphabet=ALPHABET)` генерирует все варианты слова с расстоянием редактирования равным 1 (удаление, замена и вставка символов).
  - **Исправление лемм:**  
    Функция `fix_lemmas(sent_path, lemma_path, output_path, dictionary)` обрабатывает файлы с предложениями и леммами, заменяя некорректные леммы (с префиксом `!!`) на корректные варианты, найденные среди соседних слов по словарю. Специальные токены (например, `pn`, `di` и `pron`) остаются без изменений. При этом выводится прогресс обработки и ведется статистика по количеству исправленных лемм.
- **cbow_maker.py**  
  Скрипт для обучения модели CBOW (Continuous Bag-of-Words) на аварском корпусе текстов с использованием библиотеки Gensim. Он выполняет следующие шаги:

  - **Загрузка и фильтрация корпуса:**  
     Функция `load_corpus_filtered(fname)` читает файл построчно, разбивает каждую строку на слова и фильтрует их. При фильтрации исключаются слова, которые:
     - Короче 2 символов.
     - Присутствуют в множестве `IGNORE_TOKENS` (в нижнем регистре).  
     Результатом является список документов, где каждый документ — это список отфильтрованных слов.


  - **Обучение модели Word2Vec (CBOW):**  
     Используя объединённый корпус, скрипт тренирует модель Word2Vec с параметрами:
     - `vector_size=80`: размерность векторного пространства (вектор каждого слова будет иметь 80 измерений).
     - `window=3`: размер окна контекста.
     - `negative=15`: число негативных примеров для негативного сэмплинга.
     - `alpha=0.025` и `min_alpha=0.0001`: начальная и минимальная скорости обучения.
     - `min_count=1`: игнорируются слова, встречающиеся менее двух раз.
     - `sg=0`: выбор алгоритма обучения CBOW.
     - `epochs=30`: количество эпох обучения.

  - **Извлечение векторного словаря:**  
     После обучения модели создаётся словарь, где каждому слову сопоставляется его векторное представление.
